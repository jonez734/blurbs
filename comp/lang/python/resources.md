# Python Learning Resources

Here are some recommended resources to help you learn and master Python.

---

## Official Documentation

- [Python.org](https://python.org) - Official Python website
- [Python Documentation](https://docs.python.org/3/) - Official documentation for Python 3

---

## Interactive Tutorials

- [Codecademy Python](https://www.codecademy.com/learn/learn-python-3) - Interactive lessons
- [Try Python](https://try.python.org/) - Official interactive tutorial

---

## Books

### For Beginners
- **Python Crash Course** by Eric Matthes
- **Automate the Boring Stuff** by Al Sweigart (also available free online)
- **Learn Python the Hard Way** by Zed Shaw

### Intermediate
- **Fluent Python** by Luciano Ramalho
- **Effective Python** by Brett Slatkin

---

## Video Resources

- [Corey Schafer's YouTube Channel](https://www.youtube.com/user/schafer5) - Excellent Python tutorials
- [Python Essentials** by Microsoft Learn](https://learn.microsoft.com/en-us/training/python/)

---

## Practice Platforms

- [LeetCode](https://leetcode.com/) - Coding challenges
- [HackerRank](https://www.hackerrank.com/) - Practice problems
- [Project Euler](https://projecteuler.net/) - Mathematical/programming problems
- [Real Python Tutorials](https://realpython.com/) - In-depth tutorials

---

## Community

- [Python Discord](https://pydiscord.com/) - Active community
- [r/learnprogramming](https://reddit.com/r/learnprogramming) - Reddit community
- [Stack Overflow](https://stackoverflow.com/questions/tagged/python) - Q&A

---

## Development Environments

### Text Editors
- [Visual Studio Code](https://code.visualstudio.com/) - Popular, free editor
- [PyCharm](https://www.jetbrains.com/pycharm/) - Full IDE (Community edition is free)

### Online IDEs
- [Replit](https://replit.com/) - Browser-based IDE
- [Google Colab](https://colab.research.google.com/) - Notebook environment
